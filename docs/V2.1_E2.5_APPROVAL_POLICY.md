# v2.1 E2.5 · 双签/多签审批网关升级

**发布日**: 2026-07-17
**Track**: Copilot Agent · E2.5 Approval 网关升级
**依赖**: v2.0 CopilotApproval 表 · v2.1 E2.3 长期记忆

## 目标

让 Copilot Agent 敏感操作走"多人签核"审批链：

- 双签工具白名单：`abort_mission`, `batch_delete_drones` 等强制两人签核
- 风险阈值触发：`risk_level ≥ high` 时自动升级双签
- 必需角色矩阵：必须由 `admin + compliance` 两种角色分别签
- 单签放行：`superadmin` 无视双签规则

## 架构

```
┌────────────────────┐   ┌──────────────────────────┐
│ CopilotApproval    │   │ CopilotApprovalPolicy    │
│ (v2.0, 保留原状)   │   │ (v2.1 新增, per-org 一份)│
│  - decision         │   │  - dual_sign_tools[]     │
│  - approver_id      │   │  - dual_sign_min_risk    │
│  - approved_at      │   │  - required_roles[]      │
└─────────▲──────────┘   │  - bypass_roles[]        │
          │              └──────────────────────────┘
          │
┌─────────┴──────────────┐
│ CopilotApprovalSignoff │  (v2.1 新增, 一次审批 N 签)
│  - approval_id (FK)    │
│  - signer_id, role     │
│  - decision (approve/reject)
│  - comment             │
│  - created_at          │
└────────────────────────┘
```

设计原则：**不改 v2.0 表**，通过外挂表补齐多签能力，保持向后兼容。

## 决策逻辑

```python
def evaluate_requirement(tool_name, risk_level, policy):
    if tool_name in policy.dual_sign_tools:
        return (needs=2, roles=policy.required_roles)
    if risk_level >= policy.dual_sign_min_risk:
        return (needs=2, roles=policy.required_roles)
    return (needs=1, roles=[])

def resolve_final(signoffs, needs, required_roles):
    if any(reject): return "reject"    # 任一 reject → 立即终止
    approves = filter approve
    if required_roles:
        if not all_roles_covered(approves): return None  # 角色覆盖不足
    if len(approves) >= needs: return "approve"
    return None  # 继续等待
```

## REST API

| Method | Path | 说明 |
|---|---|---|
| GET | `/api/v1/copilot/approval-policy/me` | 拉取当前 org 策略 |
| PUT | `/api/v1/copilot/approval-policy/me` | upsert 策略 |
| POST | `/api/v1/copilot/approval-policy/approvals/{id}/sign` | 提交一次签核 |
| GET | `/api/v1/copilot/approval-policy/approvals/{id}/status` | 查询签核进度 |

**status 响应示例**:
```json
{
  "approval_id": "...",

  "signoffs": [

  ]

```

## 核心不变式

1. **禁止同人重签**：`(approval_id, signer_id)` unique 索引
2. **reject 立即终止**：任一 reject → final_decision="reject"，不再等其他签核
3. **role coverage**：`required_roles` 配置时，双签必须由不同角色分别签
4. **org 隔离**：所有 API 按 `user.org_id` 强隔离
5. **回写 CopilotApproval**：final_decision 决定后同步写回原表，保持 v2.0 UI 可读
