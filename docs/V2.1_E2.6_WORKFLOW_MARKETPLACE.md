# v2.1 E2.6 · Copilot Workflow 市场

**发布日**: 2026-07-17（夜间）
**Track**: Copilot Agent · E2.6 Workflow 分享/克隆/评分
**依赖**: v2.0 CopilotWorkflow · v2.1 E2.3 长期记忆 · E2.5 审批策略

## 目标

让用户可以像逛应用商店一样浏览、克隆、评分其他团队/个人共享的 Copilot workflow。

## 数据模型

**不改** `CopilotWorkflow` 现有表，新增三张外挂表：

```
CopilotWorkflowListing   1  -──<  N  CopilotWorkflowRating
                         1  -──<  N  CopilotWorkflowInstall
```

- **Listing**: 冻结的 workflow 快照（不可变），含 title/summary/tags/visibility/dsl_yaml_snapshot
- **Rating**: (listing_id, rater_user_id) 唯一约束；stars 1-5；上支持 upsert
- **Install**: 一次克隆的审计记录（谁 clone 到哪个新 workflow）

**关键设计决策**：
- Listing 是不可变快照。原 workflow 更新后，作者需要重新发布新 listing。
- 同一 (workflow_id, workflow_version) 只能存在一条 alive listing（防止版本混乱）。
- Rating 用 upsert 语义（同人可改分），保持 avg_rating 精准。

## 可见性

| visibility | 可见范围 | 场景 |
|---|---|---|
| public | 所有 org | 官方模板、行业最佳实践 |
| org | 同 org 成员 | 内部沉淀 |
| private | 仅 direct id 访问 | 灰度测试、临时分享 |

## REST API

| Method | Path | 说明 |
|---|---|---|
| POST | `/publish` | 发布 |
| POST | `/listings/{id}/unpublish` | 软下架 |
| GET  | `/listings?q&tag&order_by&limit&offset` | 分页浏览 |
| GET  | `/listings/{id}` | 详情（含 DSL 快照）|
| POST | `/listings/{id}/install` | 克隆到自己的 org |
| POST | `/listings/{id}/rate` | 打分 (1-5) |
| GET  | `/listings/{id}/ratings` | 拉取评价列表 |
| GET  | `/listings/{id}/my-rating` | 我对该 listing 的评分 |
| GET  | `/listings/{id}/installs` | **作者专属** 谁装了我的 workflow |

## 核心不变式

1. **快照不可变**：Listing 保存 dsl_yaml_snapshot 全文，不受源 workflow 后续修改影响
2. **克隆前再验证**：install 时用 `parse_workflow + validate_workflow` 兜底，防止损坏 DSL 传播
3. **同版本单发布**：`(workflow_id, workflow_version, unpublished_at IS NULL)` 唯一
4. **命名去重**：install 到目标 org 时若同名冲突，自动加 `(2)`, `(3)`, ... 后缀
5. **不能自评**：`author_user_id == rater_user_id` 报错
6. **评分 upsert**：同人二次打分覆盖旧分，avg_rating 立即重算
7. **私有严守**：private listing 仅通过 direct id 访问；org listing 严守 org 隔离
