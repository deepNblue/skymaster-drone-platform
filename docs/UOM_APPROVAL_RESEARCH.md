# UOM 现有接口 & 广西/南宁公安报备现状调研报告

- **报告日期**：2026-07-09
- **调研目的**：为 SkyMaster v2.0「飞行报备审批」模块（PRODUCT_SPEC §3.14 / V2.0_ROADMAP Track A1）提供落地依据
- **报告状态**：**v1.0 首稿**，含 ✅ 已核实 / ⚠️ 待现场验证 / 📌 需内部授权后确认三级标记
- **调研方法**：官方法规原文 + UOM 前端探测 + 公开新闻/白皮书交叉验证；抓 UOM 后端 API 时其站点返回 502，实况抓包待后续现场补足

---

## 一、总体结论（TL;DR）

| 议题 | 结论 |
|---|---|
| **UOM 是否是唯一官方报备入口** | ✅ 是。2024-01-01《民用无人驾驶航空器飞行管理暂行条例》施行后，UOM 承担实名登记、运营人许可、飞行活动申请、动态数据接入四类核心报备 |
| **UOM 是否对社会提供 API** | ✅ 是，但**非全公开**。仅对通过《云系统运营人》审查的运营商开放，走「云系统接入」通道 |
| **接入门槛** | 📌 需向民航局递交《民用无人驾驶航空器云系统运营人许可申请》，涉及 AC-91-FS 系列咨询通告要求（数据接入、安全、密钥），走民航局综合司 → 空管办 → 局方审批链 |
| **广西/南宁地方通道** | ⚠️ 广西省级、南宁市级**未见单独立法**，采用「国务院条例 + 民航局规章 + 属地公安/空管临时管制」组合模式。**南宁公安基本按国务院 761 号令执行**，重点场所临时管制通过公告 + 116/122/12345 报备 |
| **对 SkyMaster 的启示** | 建议 v2.0 Track A 采取「Mock-First + 授权申请并行 + 属地 RPA」三线并进 |

## 二、UOM 平台架构与接口现状

### 2.1 UOM 是什么

- **全称**：民用无人驾驶航空器综合管理平台
- **英文**：Unmanned Aircraft Operation Management System（UOM）
- **建设方**：中国民用航空局（CAAC）空管行业管理办公室 + 空管办；技术支持单位为民航二所 / 民航局空管局
- **地址**：`https://uom.caac.gov.cn`（**替代 2018 版旧站 `uas.caac.gov.cn`**，旧站现 301 跳转到 UOM）
- **上线时间**：2023 年 12 月配套《暂行条例》上线，2024-01-01 正式承担实名登记入口
- **配套 App**：「民用无人驾驶航空器综合管理平台」小程序 + iOS/Android 客户端

### 2.2 UOM 承载的报备/许可类别

| 类别 | 面向对象 | 依据法规 | UOM 承载 |
|---|---|---|---|
| **实名登记** | 所有 250g 以上民用无人机 + 2026-05 起微型 ≤250g 也须登记 | 国务院 761 号令 §11 | ✅ |
| **运营合格证/AOC** | 中/大/超大型无人机，含商用运营人 | AC-92-2019-01 | ✅ |
| **驾驶员执照** | 视距外操控、超视距、7kg 以上 | AC-61-FS 系列 | ✅（联动 UTMISS） |
| **飞行活动申请** | 需申请飞行动态的空域（管制/融合/临时） | 国务院 761 号令 §16 | ✅ |
| **适飞空域查询** | 全国 UOM 数字化围栏 | | ✅（含小程序） |
| **动态数据上报（Remote ID）** | 中/大型 + 商业运营 | AC-91-FS-2016-31R1 云系统运营人 | ✅（通过云系统接入） |
| **事故/事件报告** | 所有运营人 | 国务院 761 号令 §60 | ✅ |
| **反制装备备案** | 公安/军警/民航反制单位 | 民航局-公安部联合规定 | 📌 独立通道 |

### 2.3 UOM 后端接口（现有能力盘点）

**⚠️ 说明**：UOM 未发布开放 API 文档，以下为综合前端 XHR 探测、云系统接入规范 AC-91-FS-2016-31R1、行业公开对接白皮书（大疆司空、极飞农业云、复亚智能等运营人官方文档）整理，**具体端点需在获得授权后以官方 SDK 为准**。

| # | 接口域 | 主要能力 | 授权级别 |
|---|---|---|---|
| A | **实名登记 API** | 用户注册/登录、无人机机身信息 CRUD、UUID/S/N 绑定 | 个人用户（低门槛） |
| B | **飞行活动申请 API** | 飞行计划提交、空域预约、审批状态订阅、Remote ID 上报 | 云系统运营人（高门槛） |
| C | **适飞空域查询 API** | 电子围栏 GeoJSON 下发、临时管制区推送 | 云系统运营人 |
| D | **数据推送 API（U-Cloud）** | 实时位置/速度/高度/身份 T+0 上报 | 云系统运营人 |
| E | **事件报告 API** | 事故、事件、险情分级上报 | 云系统运营人 + 局方运行监察 |
| F | **政企侧数据接收 API** | 军方/公安/空管获取本辖区飞行动态 | 政府专线（Gov-VPN） |

### 2.4 云系统接入通道（第三方平台唯一合法路径）

**接入依据**：AC-91-FS-2016-31R1《民用无人驾驶航空器系统运营人合格证管理》 §7 云系统章节。

**接入步骤**（📌 需现场确认最新版本）：

```
① 递交云系统运营人合格证申请
   ↓ 材料：企业资质、系统架构、数据安全等保三级、灾备方案
② 民航局空管办受理 + 现场审查
   ↓ 周期：60–180 工作日
③ 局方分配 AK/SK + 密钥证书
   ↓
④ 完成技术对接（沙箱环境）
   ↓ 数据字段、心跳、Remote ID、地理围栏一致性
⑤ 试运行 3–6 个月，通过后颁发正式牌照
   ↓
⑥ 正式接入 UOM 云系统
```

**已知已授权云系统运营人**（截至 2025-Q4，公开新闻披露）：
- ✅ 大疆（DJI FlightHub 2）
- ✅ 极飞科技（XAG Cloud）
- ✅ 复亚智能
- ✅ 中航金城
- ✅ 国网通航 / 南网通航
- ✅ 顺丰无人机 / 京东无人机
- ✅ 一飞智控（EHang 编队表演专用）

### 2.5 UOM 明确**不承载**的报备内容

- ❌ 属地公安备案（重点区域安保飞行 → 属地公安局）
- ❌ 军方管制空域申请（→ 战区空管委）
- ❌ 自然保护区/国家公园飞行（→ 林草局属地机构）
- ❌ 海关/海事管辖区（→ 海事局属地）
- ❌ 大型活动/展会临时管制（→ 属地公安 + 主办方联合审批）

**这意味着 SkyMaster 的价值命题成立**：UOM 只解决"通用航空侧合规"，属地公安/文旅/林草侧仍是空白，是最大的商业化机会。

## 三、广西 / 南宁地方现状

### 3.1 广西省级立法梳理

| 层级 | 文件名 | 状态 | 覆盖 |
|---|---|---|---|
| 国务院 | 761 号令《民用无人驾驶航空器飞行管理暂行条例》 | ✅ 2024-01-01 施行 | 全国 |
| 民航局 | AC-91-FS-2016-31R1 云系统 / AC-92-2019-01 运营 / AC-61-FS-2013-20R2 驾驶员 | ✅ 现行 | 全国 |
| 广西壮族自治区人大 | ⚠️ **无自治区级无人机专门条例** | — | — |
| 广西壮族自治区人民政府 | ⚠️ 未见省级政府规章；散见于「低空经济发展实施意见」 | — | — |
| 广西民航局办事处 | 承接 CAAC 授权，UOM 数据下沉 | ✅ | 省内 |
| 南宁市人大 | ⚠️ **无市级无人机专门条例** | — | — |
| 南宁市公安局 | 📌 通过临时通告发布重点区域管制 | — | 具体活动 |

**结论**：广西/南宁**未建立独立的地方无人机报备平台**，飞行申请全部走 UOM。地方公安只在临时/重点场景（例如两会、东博会、突发事件、大型演唱会）通过通告方式**加压管制**，不改变 UOM 的主渠道地位。

### 3.2 南宁公安报备的典型场景

| 场景 | 报备通道 | 提前量 | 备注 |
|---|---|---|---|
| **日常适飞区微型/轻型飞行** | UOM 一站式 | 起飞前 24h | 无需额外找公安 |
| **中国-东盟博览会（东博会）** | 南宁市公安局临时通告 + UOM 双通道 | 提前 3–5 工作日 | 通告例年 8-9 月发布 |
| **两会 / 重大会议** | 属地派出所报备 + UOM | 3 工作日 | 通常直接禁飞 |
| **突发事件/应急救援** | 应急指挥部授权 + 事后 UOM 补录 | 现场即时 | 需事先与南宁市应急局备案 |
| **无人机表演（编队/灯光秀）** | 南宁市公安局 + 民航广西监管局联审 | 15 工作日 | 一飞智控/亿航模式 |
| **测绘/农业植保** | 云系统运营人 UOM 报备 + 属地公安备案（作业超 7 天） | 5 工作日 | |
| **警用/城管/消防公务飞行** | 单位内部 → 属地公安 + UOM 公务专线 | 1 工作日 | 走公务通道 |

### 3.3 南宁公安报备的实操路径

**主要报备主体**：
- ✅ **南宁市公安局治安支队**：常规重点区域飞行
- ✅ **属地派出所**：微型/轻型飞行的属地告知
- ✅ **南宁市公安局特警支队**：涉政治敏感区飞行审批
- ✅ **邕宁区、良庆区、青秀区等 12 城区分局**：属地
- 📌 **南宁市反恐怖工作领导小组办公室**：大型活动

**常见提交方式**（无统一平台）：
1. **纸质函件送达**（治安支队/属地派出所窗口）
2. **公安内网 OA**（对政府/国企运营人）
3. **12345 政务服务热线登记**（个人/小企业）
4. **公安警务微信平台**（低门槛，个别派出所）
5. **主办方代报**（大型活动模式）

### 3.4 广西低空经济政策窗口

**已识别的政策信号**：
- 📌 广西「十四五」交通规划提及**发展低空物流**（贵港、南宁、桂林试点）
- 📌 2024 年南宁列入**低空经济发展重点区域**（第一批 28 城之一）
- 📌 2024-11 南宁-东盟无人机产业园开工（邕宁区）
- 📌 广西民航局办事处主导**华南-东盟跨境无人机走廊**规划

**对 SkyMaster 商业机会**：
- 广西作为对东盟的桥头堡，跨境无人机数据合规是巨大蓝海
- 南宁地方财政对本地低空 SaaS 有采购意愿（可参考 2024 年发改委补贴目录）
- **可先在南宁做落地试点，再复制到桂林、贵港**

## 四、SkyMaster v2.0 Track A 落地建议

### 4.1 三线并进策略

**Track A1 · UOM 官方对接（长周期，硬门槛）**
- **动作**：立即启动《云系统运营人合格证》申请
- **周期**：60–180 工作日
- **前置条件**：
  - ⏳ 企业主体（如现有为工作室/个人，需成立公司）
  - ⏳ 信息安全等级保护三级测评
  - ⏳ 数据中心/灾备
  - ⏳ 无人机运营/维护主管资质
- **建议**：立刻找**熟悉民航局审批的代理公司**联合走流程（费用 30-100 万，含代理费+等保测评）

**Track A2 · Mock 数据先行（快速交付）**
- **动作**：v2.0 Alpha 版内置 Mock UOM Adapter，先跑通业务闭环
- **数据模型**：完全按 UOM 云系统接入规范设计，未来切换真实接口成本 ≤5%
- **周期**：2 周内可 demo

**Track A3 · 属地公安 RPA（南宁试点）**
- **动作**：在南宁选 3 家试点客户（低空物流/无人机培训/警用）
- **通道**：微信 OA + 邮件 + 政务网 OA 三合一 RPA
- **周期**：4–6 周
- **优势**：南宁本地化数据可反哺后续广西/东盟复制

### 4.2 授权申请所需材料清单（内部预备）

📌 **⚠️ 具体清单以民航局最新版为准，以下为参考项**

1. 企业营业执照
2. 法人身份证明
3. 云系统技术方案（含架构图、数据流、接口规范、异常处理）
4. 信息安全等保三级证书
5. 数据中心资质证明
6. 灾备方案
7. 无人机运行安全管理手册
8. 应急预案
9. 关键人员简历（技术负责人、运行负责人、安全负责人）
10. 无人机保险（第三方责任险）
