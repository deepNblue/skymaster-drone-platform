## 二、平台基本情况

本单位自主研发的"SkyMaster 无人机统一管控平台"（以下简称"本平台"）是一套面向多协议无人机运行管控的开源软件平台，旨在为无人机运行人提供运行控制、航行服务、飞行记录等综合管理能力。平台基本情况如下：

| 项目 | 说明 |
|------|------|
| 平台名称 | SkyMaster 无人机统一管控平台 |
| 软件版本 | v1.1（已完成开发，待实机测试） |
| 开源协议 | MIT 开源许可证 |
| 部署模式 | 私有化部署（支持政务云/企业内网） |
| 技术架构 | FastAPI + React + PostgreSQL + TimescaleDB + Redis |
| 支持飞控协议 | PX4 (MAVLink)、ArduPilot (MAVLink)、DJI SDK、国产飞控适配层 |
| 核心功能模块 | 飞行报备审批、合规网关、Copilot Agent（L1-L3）、Vision AI、3DGS 三维重建、Community 社区、Model Marketplace |

## 三、咨询事项

依据《民用无人驾驶航空器运行安全管理规则》（CCAR-92部）第92.615条及咨询通告《基于计算机的民用无人驾驶航空器运行控制系统管理办法》（AC-92-FS-002，民航规〔2026〕2号），本单位拟以本平台作为**无人机云系统**向贵司申请运行批准。现就以下事项咨询：

### 3.1 申请路径确认

本平台定位为无人机云系统（面向多个运行人提供运行控制服务），拟依据 AC-92-FS-002 第5.1(2)条及第6.1.3条向飞行标准司提交申请。请确认：

（1）本平台作为多租户 SaaS/私有化部署的无人机云系统，申请路径是否正确？

（2）若本平台同时服务于自建运行控制系统的运行人（即运行人使用本平台代码自建系统），是否需要分别申请？

### 3.2 试运行批准前置条件

依据 AC-92-FS-002 第5.1(2)(b)条，无人机云系统申请人须"至少稳定运行了6个月，且具备至少100个运行人注册并使用该系统"。鉴于本平台当前处于开发完成、待实机测试阶段，请明确：

（1）"稳定运行6个月"的起算时点是否可以包含试运行批准前的内部测试与限定范围试运行？

（2）"100个运行人注册"是否要求全部为已取得运营合格证的运行人，还是包含正在申请运营合格证的运行人？

（3）是否可先取得试运行批准，再在试运行期间积累运行人数量？

### 3.3 系统功能符合性

依据 AC-92-FS-002 第7.1条，本平台已完成以下功能开发，请确认符合性：

| 规章要求 (AC-92-FS-002 §7.1) | 本平台对应实现 | 符合性自评 |
|------|------|------|
| §7.1.1(1) 航空器/操控员/运行人管理 | ✅ 多租户架构，支持航空器注册、操控员执照管理、运行人组织管理 | 符合 |
| §7.1.1(1) 运行动态监视 | ✅ 实时遥测数据接收（MAVLink/DJI SDK），地图实时显示 | 符合 |
| §7.1.1(1) 空域申报、飞行计划申请 | ✅ 飞行报备审批模块，支持向 UOM 系统提交飞行计划 | 符合 |
| §7.1.1(1) 满足 MH/T 2011-2019 数据传输要求 | ⚠️ 数据格式已参照 MH/T 2011-2019 设计，待正式接口对接验证 | 基本符合 |
| §7.1.1(2) 飞行数据记录、回放与分析（≥24月） | ✅ TimescaleDB 时序存储，支持数据回放与飞行轨迹分析 | 符合 |
| §7.1.1(3) 自查功能（过滤非真实/错误数据） | ✅ 数据质量校验模块，支持异常数据自动标记与过滤 | 符合 |
| §7.1.1(4) 告警与通知功能 | ✅ 规则引擎告警（电子围栏、高度超限、失联等），支持多通道通知 | 符合 |
| §7.1.2 数据上报频率 | ✅ 可配置上报频率，满足重点地区≥1次/分钟、人口密集区≥1次/秒 | 符合 |
| §7.1.3 通信、信息安全、电子地图、数据存储 | ✅ TLS 加密传输、RBAC 权限体系、离线电子地图、异地备份 | 符合 |

### 3.4 质量与安全管理体系

依据 AC-92-FS-002 第5.1(2)(c)条，本平台需建立参照 GB/T 19001 (ISO 9001) 的质量管理体系及参照 ICAO Doc 9859 的安全管理体系。请明确：

（1）是否要求获得 ISO 9001 认证证书，还是建立体系文件即可？

（2）安全管理体系（SMS）是否需参照特定民航行业规范，还是有推荐模板？

### 3.5 UOM 系统对接

依据 AC-92-FS-002 第8.3条，批准信息将在 UOM 平台信息查询模块发布。请明确：

（1）本平台与 UOM 系统的数据接口对接，是否需在申请前完成？接口文档如何获取？

（2）飞行计划申请、运行动态数据上报是否需直连 UOM 系统，还是通过本平台中转？

### 3.6 开源软件的特殊考量

本平台采用 MIT 开源许可证，代码公开可审查。请明确：

（1）开源软件作为无人机云系统申请运行批准，是否有额外的审查要求或限制？

（2）私有化部署模式下，不同运行人各自部署的实例，是否需要逐一审查，还是审查代码基线后统一批准？
