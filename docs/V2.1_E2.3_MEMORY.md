# v2.1 E2.3 · Copilot 长期记忆

**发布日**: 2026-07-17
**Track**: Copilot Agent · E2.3 长期记忆 & 自主学习

## 目标

让 Copilot Agent 具备"记忆"能力：

- 记住用户偏好（默认时长、常用机型、常用关键词）
- 记住组织事实（辖区 NFZ、常用 mission 模板）
- 记住任务历史（近期成功/失败的任务、时间与结果）
- 记住 Agent 自动沉淀的洞察（后续 F5 增强）

每次对话 Agent 自动召回 Top 5 相关记忆，作为 system prompt 上下文注入。

## 架构决策

| 决策 | 选择 | 权衡 |
|---|---|---|
| 存储 | Postgres 表 `copilot_memories` | 不引 pgvector，规模 < 10K/租户 SQL 已够 |
| 检索 | 关键词 LIKE + 权重打分 + 时效衰减 | 加载零 GPU 依赖；后续可平滑加 embedding 列 |
| 共享 | `scope = user | org` | 组织共享事实 vs 用户私密偏好 |
| TTL | 可配置 ttl_days | 任务历史默认 90 天过期；偏好可设永久 |
| 集成 | Agent run() 前 hook | 命中即注入 system prompt；不改 LLM 协议 |

## Ranking 公式

```
score = weight            # 0-100，人工/系统设置
      + recency_bonus     # 30 天半衰期，最高 +20
      + hit_bonus         # log2(1+hit_count)*5, cap +20
      - length_penalty    # content > 800 字 -5
      + kw_boost          # 每命中一个关键词 +8
      + tag_boost         # 每命中一个标签 +4
```

## 数据模型

```
copilot_memories:
  id              UUID PK
  org_id          UUID NOT NULL (index)
  user_id         UUID (index; NULL when scope=org)
  kind            preference | fact | task_history | insight
  scope           user | org
  key             optional dedup key (upsert on collision)
  content         text (max 4000)
  tags            JSONB list
  meta            JSONB dict
  ttl_days        int (NULL = keep forever)
  weight          0-100, default 50
  hit_count       int, default 0
  created_at, last_hit_at TIMESTAMP
  source_trace_id UUID → copilot_traces
```

Indexes:
- `(org_id, user_id, kind)` for typical search
- `(org_id, scope)` for org-shared queries
- `key` for upsert-by-key

|---|---|---|

## Agent 集成点

`CopilotAgentV2.run()` 在每回合调 LLM 前:

1. 用当前 prompt 作 query 检索 Top 5 记忆
2. 拼装为 `【长期记忆·可参考】\n1. [kind] content\n2. ...`
3. append 到 system prompt
4. 同时 emit `memory_recalled` step，并 `touch` 记录 hit_count

零副作用：LLM 失败或 db 不可用时 fall back 到"无记忆"模式。

## 自主学习: consolidate_from_trace

后台 job（未来）扫描 CopilotTrace，将成功任务自动沉淀为 `task_history`:

- 跳过 empty prompt / chit_chat / failed 任务
- 用 `trace:{trace_id}` 作 dedup key
- weight=40, ttl_days=90（低于用户显式偏好）
- meta 记 intent 和 status
