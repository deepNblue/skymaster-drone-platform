# SkyMaster v2.1 Kickoff — 三维可视化 + Agent 化操作

**版本区间**：v2.1（预计 2026-07-16 ~ 2026-10-16，3 个月）
**上游依赖**：v2.0 六大模块 MVP 全绿（见 `V2.0_DELIVERY_REPORT.md`）
**主线目标**：把 v2.0 埋点的 3DGS/Copilot 从 MVP 升级到"可对客户 Demo 的商用形态"

---

## 一、目标与非目标

### ✅ v2.1 目标

1. **Reality Studio v2** — 从 v1.1 的"单场景静态可视"跃迁到"多场景+4DGS 时序+Cesium 融合"
2. **Copilot L2 → L3** — 从"L2 官方 Playbook"跃迁到"L3 用户自定义 Agent Workflow"
3. **移动端接入** — 报备/告警/审批走 H5/小程序（v2.0 只有 Web）
4. **多租户 SLA 分级** — 引入 P0/P1/P2 客户分级（配合商务)

### ❌ v2.1 非目标（推到 v2.2）

- 训练即服务（Training-as-a-Service）
- Model Marketplace 分账系统
- 国产化推理适配（昇腾/RK3588）
- 30 城公安通道扩展

## 七、开发方法论沿用

v2.0 已验证有效的方法在 v2.1 继续沿用：

1. **Subagent + tmux 并行开发**（Track D/E/F 三线并行）
2. **CI 门禁**（压测 + 集成 UAT 强制拦截）
3. **UAT 端到端测试**（每两周一个"全链路演练"）
4. **性能对比实验**（每个新组件先跑 baseline）

新增方法：

5. **移动端专项 QA**（真机测试而非只跑 Chrome DevTools）
6. **Design Review Gate**（Cesium/Workflow 编辑器等 UI 重的模块，提交前必须过设计评审）
