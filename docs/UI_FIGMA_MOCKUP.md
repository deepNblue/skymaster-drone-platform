## 一、通用组件规格（Global Components）

### 1.1 Top Bar（顶部栏）

```

└────────────────────────────────────────────────────────────────────┘
Height: 48px  BG: #161b22  Border-bottom: 1px #30363d
```

- **Logo 区**：`88×48`，左侧 24px 内边距，Logo SVG 单色 `#39ff14`
- **搜索框**：`480×32`，居中，`bg: #0d1117 border: 1px #30363d`，占位符 `Ctrl+K 快速搜索`
- **通知铃铛**：`32×32`，右侧 24px 内边距，未读数字用 `bg: #ff3838` 圆形徽章
- **用户头像**：`32×32` 圆形 + 用户名（`font-mono` 14px）

### 1.2 Sider（侧栏）

```
├──────────────┐
│ ▎ 总览        │   ← 激活项：3px 主色左竖条 + rgba(57,255,20,0.1) 底

├──────────────┤
│  ← 收起       │
└──────────────┘
Width: 240px (展开) / 60px (收起)  BG: #161b22
```

- 展开态：24px 图标 + 12px 间距 + 14px 文字，行高 44px
- 收起态：仅 24px 图标居中，tooltip 悬停展开
- 每一项 hover：右侧 4px 主色流光动画（2s 循环）

### 1.3 Status Bar（底部状态栏）⭐ 军工感灵魂

```
┌─────────────────────────────────────────────────────────────────┐
│ ● 12/15 在线  │ ⚡ 5.6TB/24h │ 🌐 UOM OK │ 💾 92% │ 🕐 01:45:32  │
└─────────────────────────────────────────────────────────────────┘
Height: 28px  BG: rgba(13,17,23,0.9)  Border-top: 1px #30363d
Font: JetBrains Mono 12px  Color: #8b949e
```

- 每个字段以 `│` (u2502) 分隔，间距 24px
- 圆点 `●`：`#39ff14` 绿（正常）/ `#ffb000` 琥珀（警告）/ `#ff3838` 红（异常）
- 时间字段：每秒刷新，末尾秒数用 `data-flow-border` 微光下划线
- 移动端隐藏

### 1.4 Glass Panel（玻璃面板通用组件）

```
Props:
  title?:      string
  extra?:      ReactNode  (右上角操作)
  bordered?:   boolean = true
  scanline?:   boolean = false  (顶部数据流边框)
  hologram?:   boolean = false  (全息扫描线纹理)
  padding?:    'sm' | 'md' | 'lg' = 'md'  (12/16/24px)

Style:
  background: rgba(22, 27, 34, 0.6)
  backdrop-filter: blur(20px) saturate(180%)
  border: 1px solid rgba(48, 54, 61, 0.6)
  border-radius: 4px
```

- 标题栏：`h3` 字号 18px + `font-display`，左侧 4px 高主色小方块作为"军品编号感"标识
- 扫描线动效：顶部 2px 高，`linear-gradient` 从左到右流动，3s 循环

## 三、组件库清单（Component Library）

### 3.1 基础
- Button（primary / default / danger / ghost / link）
- Input / Textarea / InputNumber / Password
- Select / Cascader / DatePicker / TimePicker
- Radio / Checkbox / Switch / Slider
- Tag / Badge / Progress / Skeleton

### 3.2 数据展示
- **DataNumber**（自研）：等宽字体 + CountUp + 单位徽章
- **StatusDot**：三色圆点 + 呼吸动画
- **TelemetryCard**：遥测指标卡（数字 + 单位 + 迷你趋势）
- **AttitudeIndicator**（自研）：姿态仪表盘（Roll/Pitch/Yaw）
- **BatteryGauge**（自研）：电量弧形 + 三色渐变
- **SignalMeter**（自研）：信号强度阶梯

### 3.3 布局
- **GlassPanel**（自研）
- **HologramPanel**（自研）
- **StatusBar**（自研）
- **QuickActionDock**（底部悬浮工具栏）

### 3.4 图表（ECharts 封装）
- LineChart（默认+主色 + 数据流边框）
- BarChart / GaugeChart / RadarChart
- HeatmapChart（3D 地球图层叠加）

### 3.5 地图
- **DroneMarker**：无人机图标 + 呼吸圈
- **WaypointPin**：航点标签（P1/P2 + 参数）
- **GeofenceOverlay**：围栏多边形（红/黄/绿三级）
- **FlightPath**：轨迹线（渐变 + 时间戳）

### 3.6 视频
- **VideoTile**：单路视频格 + 遥测叠加
- **VideoWall**：N×M 视频墙布局
- **PTZController**：云台方向盘

## 四、Figma 交付规格

**要求 UI Designer 交付**：
1. **主 Frame**：8 大页面（登录 / Dashboard / 任务 / 监控 / 集群 / 模型市场 / Copilot / 报备）
2. **组件库**：全部 30+ 组件 auto-layout 化
3. **交互原型**：Login → Dashboard → 任务规划下发全流程
4. **切图**：Logo / 无人机图标 / 状态图标 · SVG
5. **文档**：Design Tokens JSON（可导入 Style Dictionary）
6. **移动版**：登录 / Dashboard / 单机监控三个核心页

**里程碑**：
- Week 1：色板 + 组件库 v0.1
- Week 2：登录 + Dashboard + 任务规划三页高保真
- Week 3：监控 + 集群 + Copilot 三页 + 移动版
