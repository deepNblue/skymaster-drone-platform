## 快速开始

### 系统要求

**浏览器要求**:
- Chrome 90+（推荐）
- Firefox 88+
- Safari 14+
- Edge 90+

**网络要求**:
- 稳定的网络连接
- 建议带宽: 10Mbps以上
- 延迟: <100ms

### 首次使用

#### 1. 访问系统

打开浏览器，访问系统地址：
```
https://skymaster.io
```

#### 2. 登录账户

使用管理员提供的账户信息登录：
- 用户名/邮箱
- 密码

#### 3. 修改密码

首次登录后，建议立即修改密码：
1. 点击右上角用户头像
2. 选择"个人设置"
3. 点击"修改密码"
4. 输入旧密码和新密码
5. 点击"保存"

## 系统登录

### 登录方式

#### 方式1: 账户密码登录

```
1. 访问登录页面
2. 输入邮箱地址
3. 输入密码
4. 点击"登录"按钮
```

#### 方式2: API Key登录（第三方应用）

```
1. 在个人设置中生成API Key
2. 使用API Key调用API
3. 请求头: X-API-Key: your_api_key
```

### 找回密码

```
1. 点击登录页面"忘记密码"
2. 输入注册邮箱
3. 查收重置邮件
4. 点击邮件中的重置链接
5. 设置新密码
```

### 双因素认证（2FA）

**启用2FA**:
```
1. 进入"个人设置"
2. 点击"安全设置"
3. 选择"启用2FA"
4. 使用Google Authenticator扫描二维码
5. 输入验证码确认
```

## 连接无人机

### 注册新设备

#### 步骤1: 进入设备管理

```
1. 点击左侧菜单"设备"
2. 点击右上角"添加设备"按钮
```

#### 步骤2: 填写设备信息

```yaml
设备ID: drone_001（唯一标识）
设备名称: Alpha Drone
设备类型: PX4 / ArduPilot / DJI
连接方式: 
  - UDP: udp:192.168.1.100:14550
  - 串口: serial:/dev/ttyUSB0:57600
  - TCP: tcp:192.168.1.100:5760
描述: 测绘无人机
```

#### 步骤3: 保存并连接

```
1. 点击"保存"按钮
2. 系统自动尝试连接
3. 等待连接状态变为"在线"
```

### 连接状态说明

| 状态 | 图标 | 说明 |
|------|------|------|
| 在线 | 🟢 | 设备已连接，可正常使用 |
| 离线 | ⚫ | 设备未连接 |
| 连接中 | 🟡 | 正在尝试连接 |
| 错误 | 🔴 | 连接失败，需要检查 |

### 连接参数配置

#### UDP连接

```
连接字符串: udp:IP:端口
示例: udp:192.168.1.100:14550

适用场景:
- 局域网连接
- WiFi连接
- 数传模块
```

#### 串口连接

```
连接字符串: serial:端口:波特率
示例: serial:/dev/ttyUSB0:57600

常见波特率:
- 57600 (默认)
- 115200 (高速)
- 921600 (数传)
```

#### TCP连接

```
连接字符串: tcp:IP:端口
示例: tcp:192.168.1.100:5760

适用场景:
- 4G/5G网络
- 远程连接
```

### 设备操作

#### 解锁/上锁

```
解锁（ARM）:
1. 确保设备已连接
2. 检查GPS信号良好
3. 点击"解锁"按钮
4. 确认操作

上锁（DISARM）:
1. 确保设备已降落
2. 点击"上锁"按钮
3. 确认操作
```

#### 起飞

```
1. 设备已解锁
2. 点击"起飞"按钮
3. 设置起飞高度（默认10米）
4. 确认起飞
5. 观察设备状态
```

#### 降落

```
方式1: 原地降落
1. 点击"降落"按钮
2. 设备自动降落

方式2: 返航降落
1. 点击"返航"按钮
2. 设备返回起飞点并降落
```

#### 紧急停止

```
⚠️ 紧急情况使用

1. 点击红色"紧急停止"按钮
2. 设备立即停止并降落
3. 仅在紧急情况下使用
```

## 创建任务

### 任务类型

| 类型 | 描述 | 应用场景 |
|------|------|---------|
| 航点飞行 | 按航点顺序飞行 | 巡检、测绘 |
| 区域测绘 | 自动生成网格航线 | 正射影像、3D建模 |
| 兴趣点环绕 | 围绕目标环绕飞行 | 全景拍摄、检查 |
| 跟随飞行 | 跟随目标移动 | 跟拍、监控 |
| 自由飞行 | 手动控制 | 自定义任务 |

### 创建航点任务

#### 步骤1: 新建任务

```
1. 点击"任务"菜单
2. 点击"创建任务"
3. 选择"航点飞行"
4. 输入任务名称和描述
```

#### 步骤2: 添加航点

**方式1: 地图点击**

```
1. 在地图上点击位置
2. 自动添加航点标记
3. 设置航点参数:
   - 高度
   - 速度
   - 悬停时间
   - 动作（拍照、录像等）
```

**方式2: 手动输入**

```
航点1:
  经度: 116.4074
  纬度: 39.9042
  高度: 50m
  速度: 5m/s
  悬停: 3秒
  动作: 拍照

航点2:
  经度: 116.4080
  纬度: 39.9050
  ...
```

#### 步骤3: 设置任务参数

```yaml
全局设置:
  起飞高度: 10m
  默认飞行高度: 50m
  默认速度: 5m/s
  完成后动作:
    - 返航降落 ✓
    - 悬停等待
    - 降落原地
  失联动作:
    - 返航 ✓
    - 降落
    - 继续
```

#### 步骤4: 验证任务

```
1. 点击"验证"按钮
2. 系统检查:
   ✓ 航点数量
   ✓ 高度限制
   ✓ 距离限制
   ✓ 地理围栏
   ✓ 电池续航
3. 查看验证报告
```

#### 步骤5: 保存任务

```
1. 点击"保存"按钮
2. 任务保存到数据库
3. 可随时调用
```

### 创建测绘任务

#### 步骤1: 绘制区域

```
1. 选择"区域测绘"
2. 在地图上绘制多边形区域
3. 调整区域边界
```

#### 步骤2: 设置参数

```yaml
飞行参数:
  飞行高度: 80m
  重叠率:
    前向: 80%
    旁向: 70%
  飞行速度: 8m/s

相机参数:
  相机型号: Sony A6000
  焦距: 16mm
  分辨率: 24MP
  拍摄间隔: 2秒

预估信息:
  航点数量: 156
  飞行时间: 25分钟
  拍照数量: 423张
  覆盖面积: 0.5km²
```

#### 步骤3: 生成航线

```
1. 点击"生成航线"
2. 系统自动计算最优航线
3. 预览航线
4. 确认并保存
```

### 任务模板

**使用模板**:
```
1. 点击"任务模板"
2. 选择预定义模板
3. 根据需要调整参数
```

### 集群飞行

#### 编队移动

```

2. 点击"移动编队"
3. 所有设备协同移动
4. 保持编队队形
```

#### 编队变换

```
1. 选择新的编队类型
2. 点击"变换队形"

```

#### 任务分配

```
智能分配模式:
- 按距离分配（最近优先）
- 按电量分配（高电量优先）
- 按能力分配（性能优先）

1. 上传任务到集群
2. 选择分配策略
3. 系统自动分配航点
4. 各设备并行执行
```

### 集群安全

#### 碰撞避免

```
系统自动监控:
- 实时计算设备间距离
- 距离<安全阈值 → 发出告警
- 距离<危险阈值 → 自动避让
```

#### 失联处理

```
单机失联:
1. 失联设备自动返航
2. 其余设备继续任务
3. 重新分配任务

多机失联:
1. 全队暂停任务
2. 等待恢复或返航
```

#### 围栏类型

| 类型 | 图标 | 说明 |
|------|------|------|
| 禁止进入 | 🔴 | 不允许进入该区域 |
| 禁止离开 | 🟠 | 不允许离开该区域 |

## 常见问题

### 连接问题

**Q: 无法连接无人机？**

A: 检查以下项：
1. 确认无人机已开机
2. 检查网络连接
3. 验证连接字符串格式
4. 确认端口未被占用
5. 检查防火墙设置

### 任务问题

**Q: 任务上传失败？**

A: 可能原因：
1. 设备离线
2. 任务验证失败
3. 航点数量超限
4. 存储空间不足
5. 通信链路不稳定

**Q: 任务执行中断？**

A: 处理方法：
1. 查看告警信息
2. 检查设备状态
3. 确认电池电量
4. 检查信号强度
5. 必要时手动控制

### 性能问题

**Q: 地图加载缓慢？**

A: 优化方法：
1. 检查网络速度
2. 清除浏览器缓存
3. 降低地图质量
4. 关闭不必要的图层
5. 使用推荐的浏览器

### 数据问题

**Q: 遥测数据丢失？**

A: 可能原因：
1. 通信中断
2. 存储空间满
3. 数据库错误
4. 网络延迟
5. 系统重启
